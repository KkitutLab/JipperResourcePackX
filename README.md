### Information
* Displays various features on the A Dance of Fire and Ice GUI.
* Originally developed by Jongyeol, forked and modified by Kkitut.
* JALib is NOT required.

### Dependency
- Need [ModMenu](https://github.com/modlist-org/ModMenu)

### Features
* Overlay
  * Progress
  * Accuracy
  * Absolute Accuracy
  * Music Time
  * Map Time
  * BPM
  * Judgment
  * Progress Bar
  * Combo
  * Judgment Strength
  * Best Record
  * Play Count
* Key Viewer
  * Hands
    * 4K
    * 8K
    * 12K
    * 16K
    * 20K
    * 10K
  * Feet
    * None
    * 2K
    * 4K
    * 6K

  * Ball Color Changer
  * Default Tile Color Changer
  * Bunny Shape Changer
